# ¿Qué diferencias deben sobrevivir?

**Autor público:** Le Matt Ansatz Di Ego  
**Programa:** Endless Monkey Project · Relational Geometry Program  
**Estado:** reflexión y solicitud de verificación independiente; P frente a NP sigue abierto.

El [verificador local](verificar_referencia_local.py) es un complemento editorial incorporado al publicar: hace reproducible el control anunciado al final del texto. Se ejecuta con `python3 -I verificar_referencia_local.py` desde esta carpeta. Es un control finito, no una prueba de economía para instancias generales.
