# Conceptual glossary

| Term | Precise use in this edition | Necessary distinction |
|---|---|---|
| Comparison | Question or operation Q with specified responses over realizations. | It is not identified by default with physical measurement. |
| Contextual reflection | Signature of responses to a family of comparisons. | It is not the same map as the linear rotation J. |
| Difference | A distinction that can be certified within a context, or a potential difference another context could discriminate, depending on the stage. | The shift in emphasis between v0.72 and v0.78 is preserved in the lineage. |
| Distinguishability information | Logarithm of the number of finite contextual classes. | It is not automatically probabilistic entropy. |
| Uncertainty of a capsule | Logarithm of the number of realizations within a finite class. | It is not the number of classes in the quotient. |
| Elementary bit | Capacity of a binary comparison to divide a class in two. | A comparison may contribute less than one global bit. |
| Contextual capsule | Class of realizations not distinguished by the available questions. | Its cardinality may differ from four. |
| Computational capsule | Class of prefixes with the same future residual function. | Equality of the functions must be certified. |
| Orbital capsule | Orbit of a nonzero seed under a J satisfying J² = −I. | It has four states, not four independent directions. |
| Sufficient boundary | Summary from which all responses covered by the contract can be recovered. | Sufficiency does not imply efficiency or universality for new futures. |
| Contextual closure | Quotient that preserves the distinctions relevant to the contract. | It is idempotent; it is not an equation of motion. |
| Phase closure | Return through iteration of an operator. | It does not guarantee physical stability under another coupling. |
| Certifiable closure | Sufficient state accompanied by a verifiable witness of its correctness. | Generating the witness may be difficult. |
| Novelty | New comparison that does not factor through the existing closure. | It does not by itself require perpendicularity. |
| Resolution | Restriction of compatible realizations. | It can occur without adding new questions. |
| Support independence | The joint signature realizes the product of the individual images. | This is not a claim of statistical independence. |
| Joint dependence | The support is not the product of its projections. | It cannot be reduced to the sizes of its marginals. |
| Channel | Admissible transformation or response shared between closures. | The mere existence of an arbitrary map, or the zero map, does not suffice. |
| Generator | Operation incorporated into a representational structure. | Its law with other generators must be specified. |
| Relational dimension | Additional representational capacity needed in a specified realization. | Distinguish label bits, linear rank, and spatial dimension. |
| Inheritance | Recoverable inclusion of the previous layer. | It does not mean storing the full history in a single interface. |
| Residual | Information or defect not absorbed by an architecture; its space must be specified. | A constraint residual is not necessarily a projection residual. |
| Holonomy | Accumulated transport around a cycle that may differ from the identity. | Exact differences of global phases yield trivial holonomy. |
| Harmonic | Element of the kernel of a specified Hodge Laplacian. | Not every metaphorical use of “harmonic” denotes this object. |
| Exact resonance | Return U^p = I on a module. | Bounded persistence need not be periodic. |
| Relational time | Observable obtained by comparing rhythms or records. | The update index does not determine physical seconds. |
| Totality T | Single identity class in the absence of discriminating comparisons, on a nonempty domain. | It is not the logical emptiness of a contradiction. |
| Certification | Procedure for justifying exactness, redundancy, or sufficiency. | A semantic definition does not provide that procedure. |
| Boundary width | Size of the references coordinated simultaneously or number of futures, depending on the definition. | Do not equate treewidth and residual width without a theorem. |

For exact historical usage, consult the [catalog](../fuentes/CATALOGO.en.md) and the [notation crosswalk](NOTACION.en.md).
