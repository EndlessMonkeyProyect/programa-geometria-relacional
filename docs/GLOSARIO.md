# Glosario conceptual

| Término | Uso preciso en esta edición | Distinción necesaria |
|---|---|---|
| Comparación | Pregunta u operación Q con respuestas declaradas sobre realizaciones. | No se identifica por defecto con medida física. |
| Reflexión contextual | Firma de respuestas ante una familia de comparaciones. | No es el mismo mapa que el giro lineal J. |
| Diferencia | Distinción acreditable dentro de un contexto o diferencia potencial que otro contexto podría discriminar, según la etapa. | El cambio de énfasis entre v0.72 y v0.78 se conserva en el linaje. |
| Información de distinguibilidad | Logaritmo del número de clases contextuales finitas. | No es automáticamente entropía probabilística. |
| Incertidumbre de una cápsula | Logaritmo del número de realizaciones dentro de una clase finita. | No es el número de clases del cociente. |
| Bit elemental | Capacidad de una comparación binaria para dividir una clase en dos. | Una comparación puede aportar menos de un bit global. |
| Cápsula contextual | Clase de realizaciones que las preguntas disponibles no distinguen. | Puede tener cardinalidad distinta de cuatro. |
| Cápsula computacional | Clase de prefijos con la misma función residual futura. | Requiere acreditar igualdad de funciones. |
| Cápsula orbital | Órbita de una semilla no nula bajo un J con J² = −I. | Tiene cuatro estados, no cuatro direcciones independientes. |
| Frontera suficiente | Resumen desde el que se recuperan todas las respuestas del contrato. | Suficiente no implica eficiente ni universal para futuros nuevos. |
| Cierre contextual | Cociente que conserva las distinciones relevantes al contrato. | Idempotente; no es una ecuación de movimiento. |
| Cierre de fase | Retorno por iteración de un operador. | No garantiza estabilidad física ante otro acoplamiento. |
| Cierre acreditable | Estado suficiente acompañado de un testigo verificable de su corrección. | Generar el testigo puede ser difícil. |
| Novedad | Nueva comparación que no factoriza por el cierre existente. | No exige por sí sola perpendicularidad. |
| Resolución | Restricción de realizaciones compatibles. | Puede ocurrir sin añadir nuevas preguntas. |
| Independencia de soporte | La firma conjunta realiza el producto de las imágenes individuales. | No afirma independencia estadística. |
| Dependencia conjunta | El soporte no es producto de sus proyecciones. | No se reduce al tamaño de sus márgenes. |
| Canal | Transformación o respuesta admisible compartida entre cierres. | La mera existencia de un mapa arbitrario, o cero, no basta. |
| Generador | Operación incorporada a una estructura representacional. | Su ley con otros generadores debe especificarse. |
| Dimensión relacional | Capacidad adicional de representación necesaria en una realización declarada. | Separar bits de etiqueta, rango lineal y dimensión espacial. |
| Herencia | Inclusión recuperable de la capa previa. | No significa guardar toda la historia en una sola interfaz. |
| Residuo | Información o defecto no absorbido por una arquitectura; su espacio debe indicarse. | Un residuo de restricciones no es necesariamente un residuo de proyección. |
| Holonomía | Transporte acumulado sobre un ciclo que puede diferir de la identidad. | Diferencias exactas de fases globales dan holonomía trivial. |
| Armónico | Elemento del núcleo de un Laplaciano de Hodge declarado. | No toda metáfora de armónico refiere a este objeto. |
| Resonancia exacta | Retorno U^p = I sobre un módulo. | Persistencia acotada puede no ser periódica. |
| Tiempo relacional | Observable obtenido de comparación de ritmos o registros. | El índice de actualización no fija segundos físicos. |
| Totalidad T | Clase única de identidad bajo ausencia de comparaciones discriminantes, en dominio no vacío. | No equivale al vacío lógico de una contradicción. |
| Acreditación | Procedimiento para justificar exactitud, redundancia o suficiencia. | Una definición semántica no proporciona ese procedimiento. |
| Ancho de frontera | Tamaño de las referencias simultáneamente coordinadas o número de futuros, según la definición. | No intercambiar treewidth y ancho residual sin un teorema. |

Para usos históricos exactos, consultar el [catálogo](../fuentes/CATALOGO.md) y la [notación](NOTACION.md).
