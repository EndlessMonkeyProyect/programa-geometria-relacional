## Reproduction

    bash reproducir_todo.sh

There is nothing to install: the verifier uses only the Python 3.9+ standard library and runs in a few seconds. The script does four things:
1. **Integrity.** Checks the SHA-256 manifest of the files as distributed.
2. **Verification.** Runs `verificar.py`, which has its own assertions and fails if a statement does not hold.
3. **O58 cross-check.** Checks that the 16 branches from (2,2,3) up to M≤200 match O58’s own `ramas_compatibles_hasta_200.csv`. Outside the repository this step is skipped.
4. **Comparison.** Compares regenerated results with `referencia_resultados/`, with tolerance rather than bit for bit: reals with `RTOL = 1e-9` and `ATOL = 1e-12`; integers, booleans, strings and structure exactly.
