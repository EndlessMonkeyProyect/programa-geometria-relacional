# De la reflexión al recierre aritmético · integración del 22 de noviembre de 2026

**Le Matt Ansatz Di Ego** · Endless Monkey Project · Relational Geometry Program

La [actualización consolidada](ACTUALIZACION_CONSOLIDADA_ES.md) conecta el orden conceptual de unidad, reflexión y distinción con realizaciones aritméticas y funcionales. Presenta identidades exactas de octavas, acarreo y recierre de Möbius; separa sus mediciones finitas de las condiciones globales formuladas para estudiar la hipótesis de Riemann.

## Lectura y reproducción

- [Documento maestro](ACTUALIZACION_CONSOLIDADA_ES.md) — exposición y mapa de soportes.
- [Matriz de resultados](MATRIZ_RESULTADOS.csv) — alcance de cada identidad, medición y condición.
- [Índice de archivos y hashes](INDICE_ARCHIVOS.csv) y [manifiesto SHA-256](MANIFIESTO_SHA256.txt) — procedencia e integridad.
- [Verificador](verificar_paquete.py) — controles aritméticos exactos e integridad del paquete.
- [Fuentes y laboratorios](SOPORTES/) — 16 ZIP históricos y sus desarrollos extraídos; se conservan como soportes de la síntesis.

Desde esta carpeta, ejecutar `python3 verificar_paquete.py`. El programa usa la biblioteca estándar de Python y comprueba los archivos del manifiesto, los 16 ZIP históricos y los controles aritméticos finitos.

## Edición pública

El documento de origen se cotejó con el ZIP adjunto: ambos tenían SHA-256 `3d5af78a62dbff7718209674dfb92562670b4f796cef7186bd31d1cae59f245b`. Esta copia para GitHub normaliza la firma pública, compone las ecuaciones de bloque con la sintaxis de GitHub y define el retorno diádico citado en la tabla de criterios.

La selección pública excluye una fuente TeX con metadatos de identidad personal. La [fuente de Mersenne preparada bajo seudónimo](SOPORTES/FUENTES_CONCEPTUALES/mersenne_orientacional_Le_Matt_publication_clean.tex) conserva el desarrollo matemático; dos fuentes TeX normalizan únicamente la grafía del seudónimo.
