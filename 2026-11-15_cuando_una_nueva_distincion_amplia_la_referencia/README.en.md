# When a New Distinction Extends a Reference

**Public author:** Le Matt Ansatz Di Ego · **Date:** November 15, 2026 · **Status:** note for editorial review.

The [Spanish manuscript](Nota_final.md) formalizes when a query distinguishes states grouped by an earlier reference. It develops normalization by least common multiple and an orthogonal projection decomposition. It applies this framework to a weighted Goldbach correlation and compares the roles of phase in Navier–Stokes and transport order in Yang–Mills. The Goldbach condition is a **conditional certificate**; a seed with uniform estimates remains to be constructed.

The [Python verifier](Verificar.py) checks finite grid, projection, and reflection identities using the standard library. Run `python Verificar.py`; the supplied [output](Verificacion.txt) records 4,427 finite checks and the value of G(30). The general arguments and open conditions are stated in the manuscript.
