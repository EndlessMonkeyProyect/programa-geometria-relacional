# De la semilla heredada a la recuperación funcional · O58 v2.1

**Le Matt Ansatz Di Ego** · Endless Monkey Project · Relational Geometry Program · 22 de noviembre de 2026

La [edición bilingüe completa](DEMOSTRACION_HILADA_BILINGUE_v2_1.pdf) reúne el [manuscrito español](DEMOSTRACION_HILADA_ES_v2_1.pdf) y la [traducción inglesa](CHAINED_DEMONSTRATION_EN_v2_1.pdf). La cadena establece identidades de Pell y Möbius y un presupuesto de recuperación funcional. La equivalencia con la hipótesis de Riemann usa el criterio clásico de Báez-Duarte; la convergencia global requerida queda abierta.

Las [fuentes LaTeX](src/) y el [verificador](proofs/VERIFICAR_CADENA_O58_MOBIUS.py) acompañan los PDF. El verificador reproduce 1.648 controles finitos exactos. La [concordancia bilingüe](CONCORDANCIA_BILINGUE.md) compara las secciones y la [nota editorial ES/EN](NOTA_EDITORIAL_ES_EN.md) precisa una referencia bibliográfica y el dominio del lema espectral sin alterar la edición v2.1.

El [manifiesto de publicación](MANIFIESTO_PUBLICACION_SHA256.txt) cubre además ese manifiesto y las tres guías nuevas. Ejecutar desde esta carpeta: `python proofs/VERIFICAR_CADENA_O58_MOBIUS.py`.
