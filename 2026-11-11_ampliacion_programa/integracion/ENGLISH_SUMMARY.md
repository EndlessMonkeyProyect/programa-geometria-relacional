# From Distinction to Economy — complementary research package

**Endless Monkey Project**  
*Relational Geometry Program*  
Conceptual date: November 11, 2026. Status: integration proposal under review.

This package connects the program's conceptual sequence (indeterminacy, difference, reference, observable distinction, inheritance, closure, recoverable information, recognition, and total computational economy) to a typed mathematical contract.

Its central finite-state proposition is a minimal **supplementary fixed-length information** result. Let `Φ:X→S` be an old signature and `q:X→Y` a new question, for finite nonempty `X`. For each old signature `s`, count the number of distinct `q` answers present in that fiber; let `k` be the maximum of these counts. The least number of extra fixed-length bits that lets the old signature recover the new question is `ceil(log2 k)`. This is an information bound, **not** an algorithmic time bound. Proofs, exact counterexamples, a small Python laboratory, and a ROSI obligations matrix are included.

The package reuses previous theorems of contextual reclosure and cost rather than claiming independent discovery. Physics correspondences and general complexity implications remain explicit research obligations.
