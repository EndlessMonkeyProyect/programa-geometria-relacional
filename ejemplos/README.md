# Comprobaciones editoriales

Ejecutar con Python 3:

~~~bash
python3 ejemplos/comprobaciones.py
~~~

No necesita bibliotecas externas. No es el código original de las fuentes.

Verifica:
1. novedad plena, parcial y redundancia mediante firmas finitas;
2. composición exacta de x = s y s = y al eliminar la referencia compartida;
3. compatibilidad conjunta que no se reconstruye desde márgenes aislados;
4. órbita de cuatro bajo el giro estándar;
5. residuo nulo cuando la comparación permanece en el subespacio heredado;
6. anulación de la semilla cuando se usa también como eje;
7. diferencia entre estado mixto y superposición uniforme;
8. ciclo armónico del triángulo y desaparición al añadir una cara;
9. cancelación de diferencias exactas sobre un ciclo.

Los controles son ilustraciones de identidades y obstáculos concretos. No generan una teoría física, no resuelven SAT general y no completan el puente P03.
